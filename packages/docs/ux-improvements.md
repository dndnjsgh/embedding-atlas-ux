# 임베딩 아틀라스 UX 개선 기록

프로젝트의 기능 설명·우선순위 선정·투어와 미니맵·대시보드·하이라이트와 수동 분석·보고서 검토 대화 6개와 현재 코드를 바탕으로 정리했다. 보고서에서 구현을 가정했던 내용은 완료 근거로 사용하지 않는다.

## 구현 기능

| 기능 | 현재 구현 |
| --- | --- |
| 가이드 투어 | 전체 분포와 지역 탐색을 안내하는 카메라 이동, Next 수동 진행, Skip, 직접 지도 조작 시 중단, 사용자 정의 단계 설정 |
| 미니맵 | 전체 분포의 대표 점 표시, 현재 뷰포트 사각형, 메인 지도 줌·패닝 동기화, 클릭·드래그 이동 |
| 전체 대시보드 연결 | 기존 Viewer의 검색·데이터 목록·차트를 재사용하고 투어·미니맵 config 전달. Wine Reviews 데이터와 사전 계산 좌표를 사용하는 데모 제공 |
| 검색 하이라이트 | Focus: 전체 배경을 흐리게 유지하며 결과 강조. Context: 2차원 반경 내 이웃 표시. Compare: 고정 A와 현재 B, 교집합을 구분 |
| 검색 범위 표시 | 내장 전문 검색의 전체 일치 ID를 지도에 표시하고 상세 레코드는 최대 500개 로딩. 두 개수를 구분해 표시 |
| 검색 근거 | 정확·부분·의미 검색 구분, 원문 일치 구간, 원래 점수와 알려진 지표의 유사도, 필터 맥락, 정렬과 관련성 피드백 |
| 호버 안정화 | 확대 수준과 밀도에 따른 선택 반경, 기존 툴팁을 유지하는 여유 반경으로 인접 점 사이 깜빡임 완화 |
| 수동 분석 | 태그, 군집 생성·이름 변경·병합·분리·삭제, 좌표 기반 k-means, JSON/CSV 내보내기 |
| 군집 지도 표시 | 체크한 군집의 색상 강조, 군집 이름과 연결선, 점을 가리지 않는 이름표 위치 탐색 |

## 범위와 제한

- 투어는 지도 탐색 안내이며 모든 사이드바 버튼을 가리키는 튜토리얼은 아니다.
- Context와 수동 k-means는 투영된 2차원 좌표를 사용한다. 원래 고차원 임베딩의 의미 유사도와 구분해야 한다.
- 유사도를 검색 정확도나 확률로 해석하지 않는다. 신뢰도 등급은 검증된 보정 설정이 있을 때만 제공한다.
- 검색 피드백과 비교 고정은 세션 범위이며 서버 학습 기능이 아니다. 검색 상세 목록의 정렬은 로딩된 레코드에 적용된다.
- Wine Reviews 데모는 외부 데이터 다운로드가 필요하다. 프로덕션 빌드에는 density-clustering WASM 산출물 등 빌드 의존성이 필요하다.
- EmbeddingView는 배열 기반 캔버스이고 EmbeddingViewMosaic는 Mosaic 데이터 질의·선택과 연결하는 컴포넌트다. Mosaic를 이미지 타일 뷰로 설명했던 이전 대화는 부정확했다.
